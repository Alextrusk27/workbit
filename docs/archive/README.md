Прошлые редакции политики конфиденциальности, пользовательского соглашения и оферты.
Нужны, чтобы по дате согласия пользователя можно было показать текст, действовавший
в тот момент.

Имя файла — исходное имя документа и дата редакции из его шапки:
`privacy-policy-2026-08-16.md`. Складывать сюда уходящую редакцию перед публикацией
новой; действующая всегда лежит в `docs/`.
